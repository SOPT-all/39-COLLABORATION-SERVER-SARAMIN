# 도메인 용어 정의

PRD 용어집 기반. 구현 시 아래 정의를 따른다.

## 핵심 개념

### 마이핏(MY FIT) 키워드
검색 결과 왼쪽에서 추가·삭제하는 관심 조건.
관심 직무·기술 조건을 조정하며 공고를 찾는 데 쓴다.

- 초기 키워드 출처: **미정**
- 다중 키워드 결합 방식(AND/OR): **미정**
- 서버 저장 여부: **미정**

일반 검색 필터와 혼동하지 않는다.

### 공고 카드 / 원자료
- **카드**: 공고를 요약한 목록 항목
- **원자료**: 기업이 공고에 제공한 업무·경력·요건·급여 등의 원문 정보

원자료는 AI가 새로 추정한 정보가 아니다.

### 경험 일치 정보
내 경험·키워드와 공고 요건이 어떤 근거로 연결되는지 보여주는 참고 정보.

- 합격률이나 지원 자격의 최종 판정이 **아니다**
- 유저 스킬과 공고 요구 스킬의 **교집합을 계산하는 규칙 기반 로직**이다
- LLM을 호출하지 않는다
- 공고 원문에 없는 값을 추정하지 않는다

### 체크 / 저장
서로 다른 동작이며 분리해서 구현한다.

| 구분 | 의미 | 상태 보유 |
|---|---|---|
| 체크 | 지금 비교할 공고를 선택 | 클라이언트 (휘발성) |
| 저장 | 나중에 다시 볼 공고를 보관 | 서버 (영속) |

둘 다 지원 제출과 구분한다.

### 서류 패키지(봉투)
이력서·자기소개서·경력기술서 등 준비한 서류의 묶음.

- 드롭하는 대상은 **봉투**이며 공고 자체를 끌어다 놓는 것이 아니다
- 실제 파일 업로드·저장은 범위 밖이다
- 요구 서류 충족 판정 기준: **미정**

### 어플라이 홈 / 간편 지원
홈에서 봉투를 공고에 연결하고 필요한 서류를 확인·보완한 뒤
지원으로 이어지는 경험.

**실제 지원 제출은 구현하지 않는다.**

### 개인화 커리어 브리핑 / D-Day
- **브리핑**: 관심 직무 공고와 추천 이유·주요 조건의 요약 영역
- **D-Day**: 공고 마감까지 남은 기간

## 도메인 패키지 매핑

| 패키지 | 담당 개념 |
|---|---|
| `user` | 사용자, 보유 스킬·경험 |
| `jobposting` | 채용공고, 원자료, 요구 스킬, 공고 타입 |
| `keyword` | 마이핏 키워드 |
| `bookmark` | 공고 저장 |
| `document` | 서류 패키지, 요구 서류 |

## 미결 사항

아래는 PRD에서 미확정 상태다. 임의로 결정하지 않고 확인 후 반영한다.

| 항목 | 내용 |
|---|---|
| OQ-01 | 키워드 초기 출처, AND/OR 결합, 동의어, 빈 결과 처리 |
| OQ-04 | 비교 최대 개수, 화면 형식 |
| OQ-05 | 서류 충족 판정 기준 |
| OQ-06 | 로그인·권한 포함 여부 |
| 상태 유지 | 마이핏 키워드의 서버 저장 여부 |
